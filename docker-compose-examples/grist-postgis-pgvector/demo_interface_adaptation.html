💻 Activation dans votre environnement

Pour voir l'interface adaptée en fonctionnement :

  1. Compiler Grist avec les extensions : npm run build
  2. Démarrer le serveur : npm start
  3. Créer un nouveau document dans Grist
  4. Ajouter une colonne → Types "Geometry" et "Vector" disponibles
  5. Choisir un widget → Map/GeometryEditor/VectorEditor disponibles

URL d'accès : http://localhost:8484
